1. What is the main practical difference between a list and a tuple in Python?
>> The main practical difference between a list and a tuple in Python is that lists are mutable,
   meaning their elements can be changed after creation, while tuples are immutable, meaning their
   elelments cannot be changed after creation. This makes tuples more suitable for fixed collections
   of items, while lists are better for collections that may need to be modified.

2. What will this code print, and why?
```
nums = [1, 2, 3]
nums.append(4)
print(nums)
```
>> [1, 2, 3, 4].
>> because the append() method adds an element to the end of the list, modifying the original list in place.


2. Given this data:
```
students = [
    {"name": "Amin", "grades": [80, 90, 70]},
    {"name": "Sara", "grades": [60, 75, 85]},
]
```
How would you access Sara’s second grade (75) using indexing?

>> students[1]["grades"][1]
>> call the second element of the students list (Sara's dictionary), then access the "grades"
    list within that dictionary, and finally access the second element of that list (index 1)
    to get Sara's second grade, which is 75.
