1. What is the difference between int and float in Python? Give one example value for each.
>> The difference between int and float in Python is that int represents whole numbers without a decimal point, while float represents numbers with a decimal point.

3. What does this code print, and why?
```
x = 10
y = 3
print(x / y)
```
>> 3.3333333333333335.
>> because the division operator (/) in Python returns a float value even if both operands are integers.

3. How would you format a float 3.14159 to show only 2 decimal places in an f-string?
>> You can format a float to show only 2 decimal places in an f-string by using the following syntax:
```python
value = 3.14159
formatted_value = f"{value:.2f}"
print(formatted_value)  # Output: 3.14"
```
